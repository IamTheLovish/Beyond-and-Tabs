Beyond and Tabs

A real-time strategy mod for Minecraft: a Beyond All Reason-style economy and tech tree, with Totally Accurate Battle Simulator ragdolls as your army. Build, tech up, and send the wobbly men over the hill.

Download for Windows
BeyondAndTabs-Setup.exe · 6 MB · Windows 10 / 11, 64-bit
Needs a Minecraft: Java Edition account

One click, then sign in

The installer sets up everything the game needs in its own folder. Nothing touches your existing Minecraft install.

Gets the launcher

Downloads Prism Launcher (portable) into %LOCALAPPDATA%\BeyondAndTabs.

Gets the modpack

Pulls the current tester build straight from the mod author's releases, so you always match the host.

Installs the mods

Forge 47.4.0 plus all 20 mods, each verified against its checksum.

Makes a shortcut

“Beyond and Tabs” on your Desktop and in the Start Menu. That is your Play button from now on.

After the installer finishes

  1. Prism Launcher opens and asks for an account. Click Add Microsoft and sign in with the account that owns Minecraft: Java Edition.
  2. Select BeyondAndTabs-test and click Launch. The first start takes a minute or two while Java and Minecraft itself download.
  3. Next time, use the Desktop shortcut. It goes straight to the game.

Windows will probably warn you. The installer is not code-signed, so SmartScreen shows “Windows protected your PC”. Click More info, then Run anyway.

Playing with a friend

Host

Title screen→Skirmish→Host Online

After a few seconds the chat shows an address ending in .e4mc.link. Click it to copy it and send it to your friend. No port forwarding needed.

Join

Multiplayer→Direct Connection→paste the address→Join Server

The lobby opens for everyone. Pick factions, colours and teams, fill empty seats with bots if you like, press Ready, and the host clicks Start Battle.

Dropped out? Rejoin with the same name and you get your side back. Anyone who joins after the battle starts becomes a spectator.

On a Mac

There is no one-click installer for macOS yet, but setup is short:

  1. Install Prism Launcher and sign in with your Microsoft account.
  2. Download BeyondAndTabs-test-mac.mrpack (Apple Silicon) or BeyondAndTabs-test.mrpack (Intel).
  3. In Prism: Add Instance → Import → Browse → pick the file → OK. Tick “I trust this modpack” when asked.

If something goes wrong

“Your mods do not match the server”

Host and guest must be on the same build. Run the installer again; it refreshes the modpack to the current tester release and leaves everything else alone.

Install stopped partway

Usually a network hiccup. Run it again; finished parts are skipped.

Removing it

Delete the BeyondAndTabs folder in %LOCALAPPDATA% and the Desktop shortcut. That is the whole install.
