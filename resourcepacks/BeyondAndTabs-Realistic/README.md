# Beyond and Tabs - Realistic (prototype, round 3)

Original block textures for the realistic look, generated by `tools/gen_blocks.py` (procedural, deterministic) -
nothing here is copied, traced or upscaled from another pack. 128 texels per block with LabPBR 1.3 maps
(`_n` normal + AO + height, `_s` smoothness / F0 / porosity) for shader packs such as Complementary through Oculus;
without a shader pack only the colour textures are used.

The textures are not stored in git (the repo ignores `*.png`): run `python3 tools/gen_blocks.py` to write them into
this folder. The eyes workflow does that before every tour and fails if the pack comes out empty.

Calibrated against numbers measured from a reference pack (`tools/pack_study.py`, numbers only): brightness, spread,
saturation and mean surface tilt per material, measured at the scale the RTS camera samples. Covers grass (top, side,
side overlay), dirt, stone, cobblestone, sand, gravel, oak log (side, top), oak planks, and (round 3, the blocks the
RTS view shows most after grass and water) stone bricks, polished andesite, smooth stone (+ slab side) and spruce
planks. Part of Beyond and Tabs (GPL-3, see the repo's LICENSE).
